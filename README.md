# Graduate-Admission-Prediction
A Machine Learning project that predicts graduate admission chances based on academic and other applicant-related features using data analysis and predictive modeling.
# Graduate Admission Prediction

## Overview
This project focuses on predicting the probability of graduate admission using Machine Learning. It analyzes applicant-related features and uses them to estimate admission chances.

## Dataset
The dataset contains applicant information and academic-related features used to train and evaluate the predictive model.

## Objectives
- Analyze the dataset using Exploratory Data Analysis (EDA).
- Understand relationships between applicant features and admission chances.
- Perform data preprocessing.
- Build and evaluate a Machine Learning model.
- Predict graduate admission chances based on input features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project File
- `graduate_admission.ipynb` — Jupyter Notebook containing data analysis, preprocessing, model building, and prediction.

## Dataset File
- `graduate_admission_dataset_500.csv` — Dataset used for this project.

## Purpose
The purpose of this project is to explore how Machine Learning can be used to analyze admission-related data and estimate graduate admission chances.
